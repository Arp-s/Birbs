# Birbs

## Presentation
Birbs is a website that aim to list the species i know and to test my ability to identify those species.
There is for each species, all it's forms (photos that are in the public domain), some fex informations about the life style, the conservation status and the repartition map.

## Front end
Front end is not the priority. The website will be improve over time but for now i need to register all the species i know and i am learning for the site to be functional.
